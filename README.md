# Radio Prywoz Home Layout

Окрема верстка головної сторінки Radio Prywoz.

## Структура

- `index.html` — головна сторінка.
- `styles/main.css` — змінні, базові стилі, контейнер, сітки, утиліти.
- `styles/pages/home.css` — стилі блоків головної сторінки.
- `scripts/pages/home.js` — скрипти головної сторінки.
- `assets/data/broadcast-schedule.json` — розклад ефіру, потік ретрансляції та власний плейлист.
- `assets/` — локальні зображення та аудіо.

## Розклад ефіру

Розклад працює в часовому поясі `Europe/Warsaw`. За замовчуванням власний плейлист грає з 10:00 до 20:00, а ретрансляція — з 20:00 до 10:00.

Щоб додати трек у денний плейлист, покладіть аудіофайл у `assets/audio/` і додайте об'єкт у масив `playlist`:

```json
{
  "id": "unique-track-id",
  "title": "Назва треку",
  "artist": "Автор або програма",
  "src": "./assets/audio/file-name.mp3"
}
```

## Запуск

Відкрити `index.html` у браузері або запустити локальний сервер:

```bash
python3 -m http.server 8080
```
